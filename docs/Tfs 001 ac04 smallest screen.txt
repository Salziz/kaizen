Kaizen TFS-001 — AC04 evidence
Criterion: Every screen stays fully usable on the smallest screen size the
platform supports, with the system text size at its largest — nothing
clipped, nothing unreachable.

Device: Android Emulator, Pixel 4a profile (small-screen AVD)
System font size: set to largest (Settings > Display > Font size > max)
System display size: default (max text scale is the binding constraint here)

Procedure:
1. Launched the Pixel 4a AVD.
2. Set system font size to its maximum value in emulator Settings.
3. Installed and launched Kaizen.
4. Visually inspected the home screen for clipped text, overflowing
   content, or unreachable UI elements.

Result: PASS. No clipping or overflow observed. The single-screen layout
(centered text in a Scaffold body) remained fully readable and unclipped
at maximum system font size on the smallest supported screen profile
tested.

Note: current screen content is minimal (placeholder text only). This
check should be re-run as real screens (describe, shortlist, cost
estimate) are added in later sprints, since layout complexity increases
the risk of overflow at max text scale.
