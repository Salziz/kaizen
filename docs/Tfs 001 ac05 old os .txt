Kaizen TFS-001 — AC05 evidence (part 2 of 2, corrected)
Criterion: The app opens and stays stable on a real device whose OS is at
least two major versions behind the latest release.

Correction note: an earlier version of this file tested on an API 31
emulator. The criterion specifies a real device, since the OEM driver
stack, vendor skin, and real memory pressure on genuine old hardware are
exactly what an emulator cannot reproduce. Re-run below uses real
hardware.

Device: Infinix Note 12i (real physical device), Android 11 (API 30)
Context: current latest is Android 16 (API 36); the stated two-major-
version floor computes to API 34 (Android 14). Android 11 (API 30) is
several major versions further behind than the minimum required,
clearing the requirement with significant margin on genuine OEM hardware
(Infinix's XOS skin over Android 11), not a stock emulator image.

Procedure:
1. Sideloaded the signed release APK onto the Infinix Note 12i.
2. Launched Kaizen from a cold start.
3. Confirmed the app opened, rendered its screen, and remained stable
   through basic navigation and a background/foreground cycle.

Result: PASS. App installed and ran cleanly on real Android 11 (API 30)
hardware, well clear of the two-major-version-behind requirement
(API 34), and on genuine OEM firmware rather than a stock AVD image.
